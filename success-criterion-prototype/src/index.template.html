WCAG Success Criterion Web Component

Easily reference success criteria by adding the success-criteria web component.

Can be displayed with varying amounts of information including number, name, description, level, and links to documentation

Known issues

  • Some part of the long descriptions (special cases) need to be formatted correctly.
  • Some content is out of date because it is dependent on the https://github.com/tenon-io/wcag-as-json repository that needs to be updated
  • The code for rendering the content needs to be refactored for easier maintenance and readability
  • The inline display of the tiny or simple mode doesn't handle spacing the way I would like.
